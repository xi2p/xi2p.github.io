# Chiwa Dictation 开发记录

## 范围

- 旧版《中日交流标准日本语》初级上 1—25、初级下 1—25（原书 26—50）、中级上 1—10。
- 五十音；按课、教材单元、日语 1—4 选课；单词Ⅰ/Ⅱ独立选择。
- 小组认读 → 主动回忆 → 选择/假名拼接 → 本轮错词巩固；复习直接测试。
- 默认静音；可选浏览器实时日语 TTS；不输入、不录音。
- 仅保存可清除的设置；学习与统计只在本轮内存中，不跨日安排任务。
- 独立静态应用全部位于根目录 dictation/，构建时复制到 dist/dictation/。
- 博客首页保留分类卡片，分隔后添加小项目卡片；README 包含用户说明与开发说明。

## 阶段

1. 检查工程和教材，确定数据来源及课号规则。
2. 提取、校对词表，记录来源与覆盖范围。
3. 实现响应式界面、学习引擎、五十音与统计。
4. 接入首页和构建；自动检查与浏览器验证。
5. 分阶段本地提交，最终推送并验证 GitHub Pages。

教材扫描件与提取中间件不提交到仓库。词表按结构化数据整理，例句为配合学习制作的简短例句。
